# 方案二：多账号管理系统

## 目标

开发一个带 GUI 的桌面应用，支持管理多个三角洲行动 QQ 号，实现**一键启动、多账号轮流自动登录 WeGame 并执行特勤处制造**。

### 2. 账号管理

**数据结构**（`accounts.yaml`）：

```yaml
accounts:
  - id: 1
    qq: "10001"
    password: "encrypted_string"   # 加密存储
    wegame_path: "D:/WeGame/wegame.exe"
    enabled: true
    last_run: "2026-05-24 09:30:00"
    run_count: 15
  - id: 2
    qq: "10002"
    password: "encrypted_string"
    wegame_path: "D:/WeGame/wegame.exe"
    enabled: true
    last_run: null
    run_count: 0
```

**安全存储**：
- 密码使用 `cryptography` 库的 Fernet 对称加密
- 密钥文件存储在用户本地 `key.key`，不随配置提交

### 3. 自动化登录模块 (`wegame_login.py`)

负责 WeGame 的完整登录流程：

```
wegame_login.py
├── launch_wegame()            # 启动 WeGame 客户端
├── wait_login_window()        # 等待登录窗口出现（OCR/图像匹配）
├── input_credentials(qq, pw)  # 输入 QQ 号和密码
├── handle_captcha()           # 处理滑块验证码（如有）
├── wait_login_complete()      # 等待登录完成进入游戏大厅
├── launch_game()              # 从 WeGame 启动三角洲行动
├── wait_game_ready()          # 等待游戏加载到角色界面
└── close_wegame()             # 登录完成后关闭 WeGame
```

**关键技术**：
- 复用现有 OCR + pyautogui 点击体系
- WeGame 窗口识别通过 `win32gui.FindWindow`
- QQ 账号密码输入通过 pyautogui 模拟键盘
- 滑块验证码：通过 OpenCV 模板匹配定位滑块缺口

### 4. 调度引擎 (`scheduler.py`)

多账号轮流执行的核心逻辑：

```python
class Scheduler(QThread):
    """在后台线程中运行，不阻塞 GUI"""
    
    signal_log = pyqtSignal(str)      # 日志输出
    signal_status = pyqtSignal(int, str)  # 账号状态更新
    
    def __init__(self, accounts):
        self.queue = collections.deque(accounts)
        self.running = False
        self.current_account = None
    
    def run(self):
        """顺序执行所有启用的账号"""
        for account in self.enabled_accounts:
            if not self.running:
                break
            self.current_account = account
            self.execute_account(account)
    
    def execute_account(self, account):
        """单个账号的完整流程：登录 → 制造 → 登出"""
        # 1. 启动 WeGame → 登录
        # 2. 启动游戏 → 进入特勤处
        # 3. 执行 do...while 制造循环（复用 main.py 逻辑）
        # 4. 退出游戏 → 退出 WeGame
        # 5. 记录完成状态
```

**执行流程**：

```
账号 A ── 登录 WeGame ──> 启动游戏 ──> 特勤处制造 ──> 退出游戏 ──> 退出 WeGame
                                                                      │
账号 B ── 登录 WeGame ──> 启动游戏 ──> 特勤处制造 ──> 退出游戏 ──> 退出 WeGame  <──┘
                                                                      │
账号 C ...                                                             └── 重复
```

### 5. 与现有制造逻辑的复用

不修改 `main.py` 核心逻辑，而是：

1. 将 `main.py` 中的制造流程抽取为可调用的函数（如 `run_manufacturing_cycle()`）
2. GUI 调度器在进程中调用该函数
3. 每个账号使用独立的配置副本（分辨率、坐标系保持一致）

## 异常处理策略

| 场景 | 处理方式 |
|------|----------|
| WeGame 登录失败（密码错误） | 记录日志，跳过该账号，继续下一个 |
| 验证码无法通过 | 超时后跳过，通知用户手动处理 |
| 游戏启动超时 | 强制结束进程，继续下一个 |
| 制造过程中断 | 记录已制造物品，登出后继续下一个 |
| 全部账号完成 | GUI 弹出通知，状态栏显示"全部完成" |

## 用户操作流程

1. 首次运行 `gui/app.py`
2. 在账号管理 Tab 点击 **[+ 添加账号]**，输入 QQ 号和密码
3. 在控制面板点击 **[▶ 一键启动全部]**
4. 程序自动：登录 A 账号 → 制造 → 退出 → 登录 B 账号 → 制造 → 退出...
5. 用户可通过日志 Tab 实时查看进度
6. 随时点击 **[⏹ 停止全部]** 终止流程
7. 程序退出后，账号密码已加密保存，下次可直接使用
