## 项目简介
点个星吧, 谢谢!

这是一个以截图、OCR 文字识别、模拟鼠标键盘操作来实现三角洲行动特勤处自动制造的程序。不会读取或更改任何游戏数据，不存在封号风险。

支持**单账号制造**和**多账号批量制造**两种模式。单账号模式下，程序自动循环检测各部门状态，收集已完成物品并开始新的制造。多账号模式下，通过 WeGame 账号切换，按顺序登录多个账号分别执行制造流程。

业务逻辑：截图 → OCR 文字识别 → 模拟鼠标键盘操作

## 增强功能

本仓库在原版单账号制造基础上新增以下功能：

### 多账号批量制造
通过 WeGame 账号切换，按顺序登录多个账号自动执行制造流程，支持：
- 账号列表管理（启用/禁用、完成时间追踪）
- 可配置的 WeGame 操作坐标和各步骤等待时长
- 三种游戏退出方式：alt_f4 / wm_close / taskkill
- GameInputSvc 抢前台自动处理
- 失败重试与超时保护

### GUI 图形界面
基于 tkinter 的图形界面，包含：
- **制造标签页**：启动/停止/暂停控制、实时部门状态卡片、运行日志、今日推荐配方
- **多账号标签页**：账号列表管理、WeGame 坐标配置、调度控制
- F8 全局快捷键

### EXE 打包支持
提供 PyInstaller 打包配置 (`build.spec`)，打包后所有资源文件置于 EXE 同级目录，方便非 Python 用户使用。

## 使用教程

### 1. 下载
前往 [Releases](https://github.com/lhdd7536/DeltaForceSS/releases) 下载最新版本的 zip 文件。
**解压到纯英文路径（Tesseract OCR 仅支持 ASCII 路径）。**

解压后得到：
- **`特勤处脚本.exe`** — 主程序，需以管理员身份运行
- **`config.yaml`** — 物品数据库
- **`user_config.yaml`** — 用户配置文件
- **`data/`** — 多账号配置数据
- **`Tesseract-OCR/`** — OCR 识别程序

### 2. 配置制造队列 (`user_config.yaml`)
```yaml
tech:                            # 技术中心
  - 高级攻势护甲片              # 要制造物品的名称，需与 config.yaml 一致
work:                            # 工程中心
  - 5.45x39mm BS
medical:                         # 医疗中心
  - 高级手术包
armor:                           # 防具中心
  - 突击装甲板
```

高级设置建议保持默认：
- `TESSERACT_PATH` — OCR 路径（一般无需修改）
- `background_mode` — 默认 `false`，开启后每轮结束最小化游戏
- `debug_mode` — 默认 `false`，开启后将截图保存到 `./log/`

### 3. 运行

**单账号模式：**
1. 打开游戏进入特勤处制造页面
2. 提前准备好无法直接购买的物品（如钛合金、中级子弹零件）
3. **以管理员身份运行 `特勤处脚本.exe`**
4. 程序会自动切换到游戏并开始循环

**多账号模式（需配置 `data/accounts.yaml`）：**
1. 配置好wegame.exe路径
2. 在 GUI 界面切换到"多账号"标签页
3. **配置 WeGame 坐标** — 每个账号的点击坐标、各步骤等待时长、退出方式等需根据你的屏幕分辨率和 WeGame 界面布局进行调整，详见 `data/accounts.yaml` 中的注释
4. 点击"启动多账号"开始自动轮转

### 4. 运行说明
- 建议将目标物品在游戏内置顶
- 只支持 16:9 分辨率（1080p / 1440p / 4K）
- 不在制造页面时程序会自动停止
- `.300 BLK` 需手动置顶（三种子弹名字相同）
- OCR 匹配失败 1 分钟后自动重启
