## 项目简介
点个星吧, 谢谢!

这是一个以截图、OCR 文字识别、模拟鼠标键盘操作来实现三角洲行动特勤处自动制造的程序。不会读取或更改任何游戏数据，不存在封号风险。

支持**单账号制造**和**多账号批量制造**两种模式。单账号模式下，程序自动循环检测各部门状态，收集已完成物品并开始新的制造。多账号模式下，通过 WeGame 账号切换，按顺序登录多个账号分别执行制造流程。

业务逻辑：截图 → OCR 文字识别 → 模拟鼠标键盘操作

## 增强功能

本仓库在原版单账号制造基础上新增以下功能：

### 多账号批量制造
通过 WeGame 账号切换，按顺序登录多个账号自动执行制造流程，支持：
- 账号列表管理（启用/禁用、预计完成时间追踪）
- 可配置的 WeGame 操作坐标（按阶段分组）和各步骤等待时长
- 三种游戏退出方式：alt_f4 / wm_close / taskkill
- GameInputSvc 抢前台自动处理、WeGame 路径自动检测
- 失败自动重试（最多 3 轮）与超时保护
- 循环执行（预约调度）：按预计完成时间自动安排下一轮，`auto_run_until_hour` 之前自动执行不弹窗
- 超出可视范围的账号（第 4/5 个）通过"滚轮次数"配置先滚动后点击登录

### 每日自动补货
每日定时（默认 2:00）自动登录各账号，导航到军需处→收集品界面，检查钛合金和高级燃料库存，低于阈值时自动购买补货，支持：
- **调度看门狗** — 每日 2:00 自动触发补货（制造进行中则等本轮结束再补）
- **手动补货按钮** — GUI 界面一键触发补货
- **独立坐标配置** — 钛合金和高级燃料使用独立的 `quantity_region` 坐标
- **补货后自动整理仓库** — 完成购买后自动执行 ESC→仓库→整理→确认

### GUI 图形界面
基于 tkinter 的图形界面，包含：
- **单账号标签页**：启动/停止控制、状态指示灯、后台/调试模式开关、制造配方显示、运行日志
- **多账号标签页**：账号列表管理、循环调度控制、自动补货配置（阈值/补货量/手动补货）、按阶段分组的 WeGame 坐标配置（支持"获取鼠标位置"）
- F8 全局快捷键（可在 `user_config.yaml` 中修改 `hotkey`），即时响应停止操作

### EXE 打包支持
提供 `build.bat` + `build.spec` 一键打包（含 Tcl/Tk 路径修复），打包后所有资源文件置于 EXE 同级目录，方便非 Python 用户使用。

## 使用教程

### 1. 下载
前往 [Releases](https://github.com/lhdd7536/DeltaForceSS/releases) 下载最新版本的 zip 文件。
**解压到纯英文路径（Tesseract OCR 仅支持 ASCII 路径）。**

解压后得到：
- **`DeltaForceSS.exe`** — 主程序，需以管理员身份运行
- **`config.yaml`** — 物品数据库
- **`user_config.yaml`** — 用户配置文件
- **`data/`** — 多账号配置数据
- **`Tesseract-OCR/`** — OCR 识别程序

### 2. 配置制造队列 (`user_config.yaml`)
```yaml
tech:
# 技术中心
  - [骨架狙击枪托, -1]
work:
# 工作台
  - [5.45x39mm BS, -1]
medical:
# 制药台
  - [精密头盔维修包, -1]
armor:
# 防具台
  - [精英防弹背心, -1]
```

高级设置建议保持默认：
- `auto_run_until_hour` — 自动执行截止小时（默认 `11`，即 0:00~11:00 自动运行不弹窗），改为 `23` 全天自动，改为 `0` 每次弹窗确认
- `TESSERACT_PATH` — OCR 路径（一般无需修改，失效时自动回退到 `dist/Tesseract-OCR`）
- `debug_mode` — 默认 `false`，开启后将截图保存到 `./log/`
- `hotkey` — 全局快捷键（默认 `f8`）
- `auto_replenish` — 自动补货配置（`enabled` 开关、`threshold` 触发阈值、`quantity` 补货量）

### 3. 运行

**单账号模式：**
1. 打开游戏进入特勤处制造页面
2. 提前准备好无法直接购买的物品（如钛合金、中级子弹零件）
3. **以管理员身份运行 `DeltaForceSS.exe`**
4. 程序会自动切换到游戏并开始循环

**多账号模式（需配置 `data/accounts.yaml`）：**
1. 配置好 wegame.exe 路径
2. 在 GUI 界面切换到"多账号"标签页
3. **配置 WeGame 坐标** — 每个账号的点击坐标、各步骤等待时长、退出方式等需根据你的屏幕分辨率和 WeGame 界面布局进行调整，详见 `data/accounts.yaml` 中的注释
4. 点击"▶ 启动全部"开始自动轮转
5. 目前 5 账号配置运行稳定（第 4/5 个账号通过滚轮次数登录）

### 4. 运行说明
- 建议将目标物品在游戏内置顶
- 只支持 16:9 分辨率（1080p / 1440p / 4K）
- 不在制造页面时程序会提示界面异常，等待 30 秒后自动重试
- `.300 BLK` 需手动置顶（三种子弹名字相同）
- 物品匹配失败时约 30 秒后自动重试
- **制造时段：0:00 ~ auto_run_until_hour**（默认 11 时），其余时间弹窗提醒，需手动点确定后继续。可在 `user_config.yaml` 中修改 `auto_run_until_hour`
